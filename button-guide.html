HTML and styling stay together.

The <button> tag creates the button. The <style> section inside this HTML file controls how it looks. Copy the whole block; no separate CSS file is needed.

What would you like to change? Each number matches a comment in the code.

1

Text on the button

Change the words between <button> and </button>. Keep both tags.

2

Size of the button

font-size changes the letters. padding adds space inside: the first value changes the top and bottom; the second changes the left and right. Larger values make the button bigger.

3

Button and text colours

background-color changes the button's fill. color changes its text. Keep the words easy to read against the background.

4

Shape of the button

Change border-radius: 0px gives square corners, 12px gently rounds them, and 999px creates a pill shape.

5

Placement on the page

In this example, edit the body rules. With display: flex, justify-content moves the button left / centre / right and align-items moves it top / middle / bottom.

Keep min-height: 100vh so the page fills the screen. padding: 32px leaves space from the page edges. On your own site, apply these layout rules to the section containing the button.
