Change one thing at a time.

Watch what moves or grows. Then look for that property in the code. The preview and copied HTML always use the same values.

Start with one line.

<button>Get help</button> makes a plain button. The version below adds six short styling lines so you can change how it looks. There is no page background or separate CSS block.

What would you like to change? The explanations stay here, so the code stays short.

1

Text on the button

Change the words between <button> and </button>. Keep both tags.

2

Size of the button

font-size changes the letters. padding adds space inside: the first value changes the top and bottom; the second changes the left and right. Larger values make the button bigger.

3

Button and text colours

background-color changes the button's fill. color changes its text. Keep the words easy to read against the background.

4

Shape of the button

Change border-radius: 0px gives square corners, 12px gently rounds them, and 999px creates a pill shape.

5

Space around the button

margin-left adds space to the left, moving the button right. margin-top adds space above it, moving it down. These are spaces around the button in the page layout, not fixed screen coordinates.

At 0px, these lines are left out of the code. Change a slider to add them. Padding = inside the button. Margin = outside the button.
